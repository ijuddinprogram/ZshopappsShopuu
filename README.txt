ZSHOPAPPS — Versi Ringan untuk Acode dan VS Code
================================================

1. Ekstrak ZIP ini seluruhnya.
2. Buka folder ZSHOPAPPS_Optimized di Acode atau VS Code.
3. Buka index.html. Di VS Code, gunakan Live Server bila tersedia.
4. Jangan memindahkan index.html terpisah dari folder assets.

Semua lagu, video pembuka, gambar, teks, dan fungsi halaman tetap disertakan.
Media telah dioptimalkan untuk mengurangi ukuran dan mempercepat pembukaan.
