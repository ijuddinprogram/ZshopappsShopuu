# ZSHOPAPPS Exclusive Sultan Store

Website statis ZSHOPAPPS yang siap dipublikasikan melalui GitHub Pages.

## Struktur file

- `index.html` — halaman utama dan seluruh fitur website.
- `favicon.ico` — ikon browser dan shortcut.
- `zshopapps-icon-32.png` sampai `zshopapps-icon-512.png` — ikon berbagai ukuran.
- `zshopapps-social-preview.png` — gambar preview saat tautan dibagikan.
- `site.webmanifest` — metadata aplikasi web.
- `README.md` — dokumentasi repository; tidak ditampilkan sebagai halaman website.

## Publikasi GitHub Pages

1. Upload seluruh file ini ke root repository.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`.
5. Simpan dan tunggu proses deployment.

Alamat target yang digunakan pada metadata:

`https://ijuddinprogram.github.io/gameplay2/`

Jika alamat repository atau domain berubah, perbarui URL absolut pada bagian `<head>` di `index.html`.
